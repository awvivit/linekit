# Security Policy

## Supported versions

Security fixes land on the default branch. Linekit is a static site: there is no server, no account system, and no uploaded-file storage in this repository.

## Reporting a vulnerability

Report security issues through [GitHub private vulnerability reporting](https://github.com/awvivit/linekit/security/advisories/new).

Please skip public issues for security reports. Reports that can be reproduced will be acknowledged, and a fix will be coordinated on the default branch.

## Scope

In scope: the static site, its build, and the supply chain of this repository (dependencies, GitHub Actions, and published Pages output).

Out of scope: vulnerabilities in a visitor's browser, and tracing behavior that is not implemented yet.
